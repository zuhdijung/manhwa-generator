# Character Bible

Folder ini adalah sumber kebenaran visual karakter. Buat satu berkas Markdown per karakter dari [template](templates/character-template.md), gunakan slug stabil (misalnya `char-arin.md`), dan simpan hanya detail yang berasal dari naskah atau telah disetujui.

## Aturan kerja

- Bedakan `CANON`, `PROPOSAL`, dan `UNKNOWN`.
- Jangan menyimpulkan warna mata, tinggi, usia, kostum, senjata, atau ciri lain dari genre.
- Status karakter harus `draft`, `in-review`, atau `approved` sebelum digunakan sebagai constraint generasi.
- Catat variasi kostum dan kondisi sementara dengan ID sendiri.
- Letakkan reference image yang sah digunakan di `references/`; catat asal, hak penggunaan, dan checksum/nama file dalam character sheet.
- Jangan memasukkan karya pihak lain sebagai target peniruan gaya atau identitas karakter.

## Checklist approval

- Siluet dan proporsi
- Bentuk wajah, mata, rambut, dan warna
- Kostum utama, material, aksesori, dan alas kaki
- Ukuran relatif terhadap karakter lain
- Ekspresi dan gesture khas
- Tampak depan/samping/belakang bila tersedia
- Detail yang dilarang berubah
